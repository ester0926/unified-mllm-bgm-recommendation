## Interpretation Notes

- UCR is lower-is-better; target suggested by advisor is roughly <= 10-15%.
- MAA is higher-is-better; target suggested by advisor is roughly >= 80%.
- PCR is higher-is-better; target suggested by advisor is roughly >= 60%.
- `wo_audio_feature_only` tests whether music feature removal alone changes the explanation while title/artist metadata remains available.
- `wo_audio_all` is the stricter counterfactual because it removes both the music feature and title/artist metadata injection.
- This first-pass analysis is rule-based and should be manually audited or replaced with LLM-as-a-Judge labels before final thesis claims.
